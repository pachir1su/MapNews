## 구현 원칙

- 날짜나 취재기자 지역을 뜻하는 `[서울=뉴시스]` 등은 장소 증거로 사용하지 않습니다.
- 서울과 같은 지명을 포함한 영화·작품명은 장소로 보지 않습니다.
- 본문 추론은 **기사 제목이 지역 사건/현장/행사 맥락이고, 도입부가 명시적으로 장소와 행위를 연결하는 경우에 한정**합니다.
- 실제 위치의 위·경도는 추론하지 않으며, 행정구역 대표 좌표는 실제 발생 주소가 아닙니다.
- 경계 사례와 표기 혼동 사례는 기사별 CSV의 `review_flags`로 별도 검토할 수 있습니다.
- 검증 데이터의 339개는 여러 시점 뉴스가 아니라 동일 보관 JSON의 전체 기사입니다. 기존 지도 샘플(341건·좌표 209건)과 직접 비교하지 않습니다.

## 자동 감사

```bash
python tools/audit_location_coverage.py --input news_results.json --cache map_visualization/.geocode_cache.json --output test-artifacts/location-audit
```

결과의 `articles.csv`는 모든 339건에 대해 제목, 기존/새 지역, 본문 도입부 증거, 지역 캐시 적중 여부, 추가 검토 플래그를 제공합니다. 개선 효과는 이 동일 입력에서의 변경 건수·캐시 적중 건수로 측정하지만, **실제 정답 기반 정확도는 독립적인 사람 검증 세트 구축 전에는 측정할 수 없습니다.**
