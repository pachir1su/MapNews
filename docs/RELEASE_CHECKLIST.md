# MapNews v0.1.0 출시 검증 체크리스트

이 문서는 릴리즈를 위한 검증 기준이며, 확인되지 않은 테스트를 완료된 것으로 표시하지 않습니다.

## 코드와 데이터
- [ ] 현재 PR의 Linux 3.11 / Windows 3.12 통합 CI 성공
- [ ] 저장소 작업 트리에서 Ruff, pytest 통합·Qt·WebEngine 결과 확인
- [ ] README 설치 명령을 빈 가상환경에서 재현
- [ ] 실제 RSS 수집으로 새 기사 30~100건 확인. 요청 오류/유효성·공급원 정책 검토
- [ ] 반복 수집 시 동일 ID 안정성, 동일 URL 수정, 서로 다른 기사 같은 제목 처리 검증
- [ ] 일부/전체 RSS 장애 및 0건으로 이전 news_results.json 무손상
- [ ] Gemini 미설정, 429/503, 부분 JSON 실패와 분석 처리량 상한을 분리 검증
- [ ] Nominatim 요청 상한 및 캐시·저장 실패 복구 검증
- [ ] 시연용 example.com/test 링크가 실기사로 열리지 않음 확인

## 통합 GUI
- [ ] 같은 실행에서 수집/분석/좌표 생성/프론트 입력의 ID와 건수 대조
- [ ] 좌표 없는 기사 목록 유지; 지도에서 임의 핀 없음 확인
- [ ] 행정구역 대표 좌표와 실제 발생 위치의 정확도 안내
- [ ] Windows 11 GUI 실제 실행(디스플레이/HiDPI/종료/오프라인 전환) 확인
- [ ] Linux GUI 실행 캡처, 기사 검색·분류·지역·북마크·원문 링크 확인
- [ ] 마커·군집 숫자가 뉴스 건수/실제 사건 수와 다를 수 있음을 UI와 발표 자료에 명시
