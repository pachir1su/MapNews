# UI 개편 테스트 인계

이번 작업은 사용자 요청에 따라 **개발만 수행**했다. pytest, OS 실행, CI, 화면 캡처를 진행하지 않았다.
커밋의 `[skip ci]`로 이번 push/PR 자동 테스트를 건너뛰며 기존 워크플로 파일은 변경하지 않는다.
이전 85개/HiDPI 39개 통과 기록은 `978b88f`에 해당하고 현재 구현의 검증 결과가 아니다.

## 변경된 계약

- `MainWindow(..., online=True)`, `MapPanel(..., online=True)`: 이제 온라인 기본값이다.
  네트워크가 필요 없는 GUI 테스트는 명시적으로 `online=False`를 넘겨야 한다.
- `MapPanel.mode` 콤보는 제거했다. `set_online(bool)`과 `online_action`/`offline_action`으로 전환한다.
- `source_label`, 별도 상세 창, 반응형 우측 상세 패널을 제거했다.
  `panel_stack.currentWidget()`은 `sidebar` 또는 `detail`이다.
- 목록 방향키는 선택만 바꾸고 클릭/Enter는 상세로 들어간다. 상세 뒤로/Esc는 목록으로 복귀한다.
- `refresh_button`은 메뉴 QAction이다. `demo_button/use_demo`는 `default_data_action/use_default_data`로 바뀌었다.
- 지도 popup을 제거했다. WebChannel 선택 → 왼쪽 상세 전환을 기준으로 확인해야 한다.
- 기사/지도 마커는 SVG다. 글자 내용을 검사하던 테스트를 아이콘 자원/종류와 선택 상태 기준으로 갱신한다.
- 가상 기사/유효하지 않은 URL은 원문 버튼을 비활성화하는 대신 숨긴다.
- WebEngine 프로필은 앱 소유로 재사용하고 페이지는 전환 때 해제한다. 프로필 해제를 매 전환마다 기대하던 테스트를 바꾼다.

기존 테스트 파일은 테스트 담당자 영역으로 남겨 두었으며 이번 변경에 맞춰 수정하거나 실행하지 않았다.

## 확인할 동작

1. 기본 OpenStreetMap 타일, 식별 User-Agent/HTTP 캐시, 저작자 표시, SVG 분류 마커/군집.
2. `--offline`의 무네트워크 실행, 전남 축약 지명, 행정구역 확대/축소와 SVG 마커.
3. 온라인 초기화/첫 타일 시간 초과·연속 오류·렌더러 실패의 오프라인 복구, 모드 반복 전환과 종료.
4. 목록/마커 선택 동기화, 상세 뒤로 복귀 시 검색·스크롤 유지, 방향키/Enter/Esc, 위조 ID 무시.
5. 검색 중 상세→목록, 필터 펼침/접기·다중 선택·지역·정렬·초기화, 빈 결과의 초기화 동작.
6. 데이터 실패 후 재시도/기존 데이터 보존, 취소/종료 중 늦은 결과 무시.
7. 제목 두 줄 말줄임, 누락 데이터·알 수 없는 분류, SVG 가독성, 시스템 색상 전환.
8. 1366×768, 1920×1080, 좁은 창과 HiDPI에서 지도 버튼/상세 본문/키보드 초점.
9. HTML 크기 제한, 로컬 SVG 경로 고정, 악성 기사 텍스트와 외부 URL 검증.

실행 여부와 결과는 테스트 담당자가 별도 기록한다. 이 문서는 통과 보고서가 아니다.

## 후속 개발: 읽기·복구·파일 연결·키보드

- 상세 상단 이전/다음 버튼은 현재 필터·정렬 순서를 따른다. 양 끝에서 비활성화한다.
- 제목·요약·메타데이터는 선택/복사 가능하다. 작성 시각이 없으면 빈 날짜 문구를 생략하고 실제 링크에는 호스트를 표시한다.
- 기사 변경 시 스크롤을 맨 위로 돌리고 상세 진입 시 본문에 초점을 둔다.
- 검색 결과의 좌표 있는 기사 집합이 바뀌면 결과 범위로 이동한다. 정렬만 바뀌거나 결과가 0건이면 지도를 강제로 이동하지 않는다.
- 온라인 지도 준비 전 결과 맞춤/전국 보기 명령을 기억한다. 목록에서 고른 기사는 해당 좌표로 이동한다.
- 로딩·실패·취소·빈 데이터·빈 검색 결과를 구분하고 실패 시 기존 목록에도 재시도 버튼을 표시한다.
- JSON 문법 오류는 행·열, 인코딩/권한/파일 누락은 별도 메시지로 안내한다.
- JSON 드래그/드롭, Ctrl+O, 마지막 폴더 기억, 더 보기 → 불러오기 정보의 경고 목록을 추가했다.
- 파일 교체 성공 시 Provider를 확정하고 검색/선택을 초기화한다. 실패하면 이전 데이터·조건을 유지한다. 취소하면 이전 Provider로 돌아간다.
- 최소 창 800×600, 1100px 미만에서 왼쪽 최대 폭 340px. 패널 비율은 재시작 시 복원한다.
- Ctrl+L/검색창 아래 방향키: 목록, Alt+위/아래: 이전/다음 기사, Alt+왼쪽/Esc: 목록 복귀.

이 후속 개발에서는 Python 문법 검사만 수행했다. pytest·플랫폼별 GUI 실행·CI는 수행하지 않았다.
이전 13개 화면 모음은 후속 개발 전 화면이다. 테스트 담당자는 특히 빠른 연속 선택, 지도 준비 전 검색,
파일 교체 실패/취소/재시도, 동일 ID를 가진 다른 파일, 긴 단어/문단, 작은 창의 키보드 초점을 확인해야 한다.
