## 화면 구조

목록과 상세가 **하나의 왼쪽 QStackedWidget**을 공유하며, 오른쪽은 지도다.
목록/마커 클릭으로 상세를 열고 뒤로/ESC로 목록에 복귀한다. 목록 위젯을 다시 만들지 않아
스크롤·검색·필터를 유지한다. 키보드 방향키는 선택만 이동하고 Enter로 상세를 연다.
검색을 입력하면 목록으로 돌아간다. 이전 3단 패널과 별도 상세 창은 제거했다.
최소 크기는 800×600, 왼쪽 폭은 320~440이다. 창 너비 1100 미만에서는 최대 340으로 줄인다.
QSplitter로 폭을 조절하며 비율을 기기에 저장한다.

검색은 항상 노출하고 카테고리/지역은 명시적인 필터 버튼 아래 펼친다.
목록은 아이콘·두 줄 제목·지역/작성 시각만 표시하며 요약은 상세에서 읽는다.
색만으로 분류하지 않는다. Lucide SVG를 목록·지도에 공통 사용하고 접근성 이름/툴팁을 제공한다.
출처 배지, 목록/지도/상세 중복 제목, 상시 상태 표시줄은 없다.
로딩 때만 진행 표시와 취소를 노출하며 오류에는 복구 동작을 제공한다.
시스템 화면 모양 설정만 따르고 수동 테마 선택은 없다.

## 지도

**기본 지도는 Folium/Leaflet/MarkerCluster + QtWebEngineView의 OpenStreetMap**이다.
JS/CSS와 SVG 아이콘은 로컬 번들이며 지도 타일에만 인터넷이 필요하다.
OSM 저작자 표시는 지도 하단에 작은 크기로 유지한다. 임의 타일 다운로드/사전 수집은 하지 않는다.
앱 식별 User-Agent를 보내고 앱 소유 QWebEngineProfile로 HTTP 디스크 캐시를 재사용한다.
페이지는 지도 전환 때 해제하고 프로필은 앱 종료 때 해제한다.

Native Qt 지도는 `--offline`, 지도 선택 메뉴, 온라인 실패 시 사용한다. Natural Earth 공개 도메인
지형과 SGIS 기반 경계를 번들로 제공한다. 시·도/시·군·구는 같은 자료에서 생성한다.
시·군·구 선은 확대 시 표시한다. 로컬 지도는 도로/건물/정밀 사건 위치 지도는 아니다.
군집 마커를 누르면 해당 기사 목록을 연다. 출처의 행정구역 원문은 보존하며
화면의 축약 지명에서 전남광주는 **전남**으로 표시한다.

초기화 15초, 첫 타일 응답 12초, 연속 타일 오류 또는 렌더러 종료 시 로컬 지도로 전환한다.
WebChannel은 기사 ID 선택과 초기화/오류 신호만 노출한다. 기사 본문을 지도에 반복 표시하지 않는다.
Python→JS 값은 JSON 직렬화, 아이콘은 고정 레지스트리로 전달한다. 알 수 없는 ID는 무시한다.
뉴스 원문 페이지는 내장 브라우저에 로드하지 않고 검증된 주소만 OS 브라우저로 연다.

## 스레드·자원 수명

Provider 로딩과 Folium HTML 생성은 별도 QThread에서 수행한다. GUI 갱신은 Qt 신호로
주 스레드에서 실행한다. 하나의 Provider 로딩만 허용한다. 창 종료는 취소 신호를 보내고
작업 완료 후 진행한다. 지도 전환 시 타이머/페이지/WebChannel을 정리한다.
오래된 지도 객체의 지연 콜백이 새 페이지를 다시 시작하지 않도록 stopped 상태를 검사한다.

## 장시간 사용과 대용량 보완

13건 이상 군집은 수백 개 메뉴 항목을 만드는 대신 검색 가능한 가상화 목록을 연다.
필터/데이터가 바뀌면 이전 군집 창을 닫아 사라진 기사를 선택하지 않게 한다.
선택 변경은 해당 마커의 강조만 갱신하며 전체 군집을 다시 만들지 않는다.
지도 경계는 제공된 좌표 범위까지 확장하며, 검색 결과 맞춤 아이콘으로 전체에 맞춘다.
로컬 GeoJSON 누락·손상 시에도 좌표 격자와 마커·목록·상세는 계속 동작한다.
로딩 중에는 진행 표시와 취소 버튼을 제공하고 취소된 작업의 늦은 결과를 무시한다.

## 저장과 불러오기 상태

`QSettings`의 `bookmarks_v1`에는 SHA-256 문자열 배열만 저장한다. 실제 기사 URL이 유효하면
URL을 식별자로, 가상 기사/URL 없는 기사는 가상 여부·ID·제목·지역 조합을 사용한다.
다른 파일이 같은 숫자 ID를 써도 제목/지역이 다르면 같은 저장으로 취급하지 않는다.
URL 없는 기사의 제목이나 지역이 변경되면 새로운 기사로 취급한다. 본문 복사나 서버 동기화는 하지 않는다.
최대 1,000건이며 한도 초과 시 기존 기록을 조용히 삭제하지 않는다. 손상된 설정은 무시한다.

`_load_active`는 스레드 종료 신호를 UI가 처리할 때까지 유지한다. 그동안 추가 열기/새로고침을 막아
이전 작업의 종료 신호가 새 작업 상태를 덮어쓰지 않게 한다. 결과/오류를 수락한 시점에
`_load_settled`를 설정해 이미 반영한 결과가 뒤늦은 취소로 표시되지 않게 한다.
동일 목록에는 모델 reset과 마커 재생성을 생략한다. 지도 범위 변경은 ID와 좌표를 함께 비교한다.
