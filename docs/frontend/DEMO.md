# 3분 시연 순서

1. 설치가 끝난 상태에서 네트워크를 끊고 `python -m frontend`로 실행합니다.
2. 우측 상단 **MOCK · 시연 데이터 20건**과 오프라인 지도를 보여줍니다.
3. 천안 기사를 선택합니다. 지도 강조, 우측 요약, 시연용 대표 좌표 안내를 확인합니다.
4. 수도권 군집 마커를 눌러 기사 메뉴에서 다른 기사를 선택합니다. 목록 선택이 따라갑니다.
5. Ctrl+K를 눌러 `수원`을 검색하고 `행사`만 포함합니다. 1건으로 줄어듭니다.
6. 초기화 후 지역을 `경기`, 정렬을 `오래된순`으로 바꿉니다.
7. 존재하지 않는 검색어로 빈 결과 화면을 보여주고 초기화합니다.
8. 다크/라이트를 전환하고 창 폭을 줄입니다. 상세 버튼 또는 Ctrl+Enter로 상세 창을 엽니다.
9. (인터넷 연결 시에만) 온라인 지도 모드로 전환합니다. 마커 클릭, 군집 확대, 전국 복귀를 보여줍니다.
10. 데이터 소스/분석은 팀원 백엔드가 담당하며, 현재 요약은 저장된 Mock임을 설명합니다.

## 시연 전에 확인

- 최소 1366×768 논리 해상도를 권장합니다. 150% 배율에서는 실제 표시 영역이 작아집니다.
- 기본 Mock는 API 키·계정·서버가 필요 없습니다. 원문 링크는 가상 기사여서 열리지 않습니다.
- 좌표가 없는 외부 JSON은 뉴스 목록/상세에는 표시되지만 지도 마커가 없습니다.
- 온라인 지도는 인터넷이 필요합니다. 완전 오프라인 시연에서는 기본 모드를 사용합니다.
- `python -m pytest -q`를 통해 환경에서 주요 기능이 동작하는지 확인할 수 있습니다.
