# 탐색 동선 중심 UI

2026-11-07. 색상뿐 아니라 **검색 → 위치/기사 선택 → 읽기 → 목록 복귀** 흐름을 정리했다.

토스 로고·전용 서체·앱 화면을 복제하지 않는다. 다음은 MapNews 용도에 맞춘 설계 판단이며

## 선택한 구성

| 판단 | 구현 |
|---|---|
| 지도 옆 3단은 같은 기사 정보를 반복하고 지도 폭을 줄임 | 목록/상세가 왼쪽 패널을 공유하는 2단 구조 |
| 클릭 후 다시 목록으로 돌아오기 쉬워야 함 | 뒤로/ESC, 기존 목록 위젯·검색·스크롤 유지 |
| 첫 화면에 모든 조건을 펼칠 필요 없음 | 검색은 노출, 카테고리/지역은 필터 버튼으로 펼침 |
| 작은 보조 문구와 카드 요약이 시선을 분산 | 목록은 두 줄 제목 + 지역/시각, 요약은 상세만 |
| 지역 맥락을 실제 지도에서 확인해야 함 | OpenStreetMap 기본, 오프라인은 대체 지도 |
| 글자 마커가 지명/뉴스 제목과 혼동됨 | 색과 Lucide SVG 기호, 군집만 기사 수 표시 |
| 데이터/기술 안내는 탐색의 주 동작이 아님 | 배지·하단 설명 제거, 더 보기 → 정보에 배치 |
| 조작할 수 없는 원문 버튼이 불필요함 | 가상 기사/잘못된 URL의 원문 버튼 숨김 |

## 자원과 화면 규칙

- Lucide 0.468.0 SVG 원본을 고정 버전으로 로컬 배포한다. 지도·목록·버튼에 같은 선형 아이콘을 쓴다.
- 이모지나 한글 한 글자 마커를 사용하지 않는다. 작은 지도 기호에는 정확한 SVG가 적합해 생성 이미지는 사용하지 않았다.
- 행정구역 데이터 원문을 수정하지 않고 축약 표시만 `전남`으로 바꾼다.
- 시스템 색상 변경은 Qt 신호로 반영한다. 수동 테마 버튼은 없다.
- OSM 저작자 표시는 지도에 유지한다. 출처 안내까지 지우는 방식은 사용하지 않는다.
- 일반 탐색 화면에 “데모”, 상태 설명, 중복 제목을 표시하지 않는다. 가상 기사 여부는 데이터 계약과 정보 창에 명시한다.

이번 변경은 개발 구현이며 화면 실행/사용성/플랫폼 테스트는 수행하지 않았다.
기존 screenshots/는 이전 화면의 기록이다. 테스트 담당자 인계는 QA_HANDOFF.md를 따른다.
