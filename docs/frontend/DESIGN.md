# UI 개편: 탐색에 집중하는 화면

2026-11-07. 사용자 피드백에 따라 장식적인 대시보드 인상과 상시 설명을 줄였다.

## 참고와 적용

- KGA의 실제 `web/assets/style.css`를 확인했다. OS 설정만 사용하는 화면 모양, 의미별 색상 토큰,
  텍스트와 채움 색의 분리를 참고했다. KGA의 검토용 `design/proposal-b-airy.html`에서는
  그림자를 없애고 여백으로 묶는 구성을 참고했다. 해당 프로젝트 파일은 수정하지 않았다.
- 토스 TDS 공식 [Typography](https://tossmini-docs.toss.im/tds-mobile/foundation/typography/),
  [Colors](https://tossmini-docs.toss.im/tds-mobile/foundation/colors/)를 확인했다.
  명확한 제목/본문/보조 정보 위계, 중립 회색 면, 절제된 파란색 동작·선택 표시를 적용했다.
  토스 로고·전용 서체·앱 화면을 복제하거나 가져오지 않았다.
- KGA 참고 코드: https://github.com/pachir1su/koreatechGongjiAgent/blob/main/web/assets/style.css

## 실제 변경

1. 상단 슬로건과 두 번째 헤더 줄을 삭제했다. 검색을 중심에 두고 새로고침은 이름/툴팁이 있는
   벡터 아이콘 버튼으로, 파일 열기·데모·지도 정보는 더 보기 메뉴로 모았다.
2. 카드마다 선을 두르지 않고 목록 행의 여백과 선택된 행의 연한 배경으로 구분한다.
   제목 24/20px, 목록 제목 15px, 본문 15px, 보조 정보 12~14px로 위계를 정리했다.
3. 하단 상태 표시줄·지도 설명 문단·기사의 URL 문자열·좌표 설명 문단을 제거했다.
   뉴스 개수는 목록에 한 번 표시한다. 좌표 설명/URL은 관련 버튼의 툴팁에서 제공한다.
   지도/데이터 출처·연도·단축키는 정보 창으로 옮겼다. 오류는 상단에 필요한 때만 표시하며,
   로딩 실패는 재시도까지 유지한다. 일시 알림은 6초 후 사라진다.
4. 수동 테마 버튼, Ctrl+T, --dark, QSettings 테마 저장을 삭제했다.
   QStyleHints.colorScheme() 및 colorSchemeChanged를 따라 목록·지도·상세를 동기화한다.
   기존 dark 설정은 제거하며, OS가 Unknown을 반환하는 환경은 밝은 화면을 사용한다.
5. 정상 지도에서 좌표 격자를 없애고 실제 시·도 경계를 표시한다. 확대하면 시·군·구 선이
   추가된다. 상세 자료 기준연도/라이선스는 MAP_DATA.md에 기록했다.
6. 좁은 창에서는 기존처럼 상세를 별도 창으로 제공한다. 넓은 창의 중복 ‘기사 보기’ 버튼은 숨긴다.

## 검토

동일 Mock 기사와 선택 상태로 1366×768, 1920×1080, 1100×700을 렌더링해 비교한다.
구조를 유지한 채 기존의 둥근 카드/주황 테두리와 새 여백/파랑 선택면을 비교했고,
뉴스 제목과 지도 영역이 더 먼저 보이는 후자를 채택했다. 실제 캡처는 screenshots/에 있다.
시스템 화면 모양은 자동 테스트에서 Qt의 변경 신호를 주입해 검증한다. 실제 Windows 설정 앱을
조작한 수동 전환 검증으로 주장하지 않는다.
