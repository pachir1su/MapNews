# MapNews 실제 기사 장소 검증 현황 (2026-11-21)

## 검증과 미검증의 경계

- 원본: 저장소 `news_results.json`의 실기사 **339건**. 이전 v3 감사에서 **141건**은 추가 검토 후보로 표시되었습니다.
- PR의 프로그램은 339건 모든 기사에 대해 제목·본문 도입부 근거·기존 vs 신규 장소·좌표 캐시 적중·검토 플래그를 기록하고, 새 규칙에서 플래그가 있는 기사를 `flagged_candidates.csv`에 분리합니다.
- `data_ai/location_gold.py`에는 실제 제목과 본문을 비교해 정한 **22개 대표 사례**가 있습니다. 각 사례의 제목 매칭은 반드시 유일해야 하며 결과가 예상 장소와 다르면 CI를 실패시킵니다.
- **검토 후보 141건 전체에 사람이 정답 라벨을 붙인 것은 아닙니다.** 기계적 339행 전수조사와 수동 근거 사례 22건을 엄격하게 구별합니다.
- 캐시 좌표 적중은 지리적 정확도가 아니라 대표 행정구역 좌표 제공 가능 여부입니다.

## 확인된 사건 장소와 혼동 사례

- 영화 「서울의 밤」: 작품 제목의 서울은 영화제 상영 위치가 아님 → 미좌표
- 영덕군청 공무원 음주운전: 기관은 영덕군, 본문 단속 현장은 포항시 북구
- 성남시 대통령 표창: 수상 기관 성남시, 시상식 장소 서울 강남구 → 단일 지점으로 확정하지 않음
- 수능 부정행위 점검 기사: 서울 은평고·중앙고를 동시에 취재 → 특정 단일 학교 핀을 표시하지 않음
- 전국 지방의회 모임: 본문은 경남 양산에서 열린 회의라고 명시
- 기타 시연·가정 훈련: 재난 시뮬레이션의 장소와 실제 재난 발생지를 구별
- 타국 뉴스·전국적 온라인 반응: 한국 지도에 임의 좌표를 넣지 않음
- 지역 소식 묶음: 여러 행사를 단일 사건 좌표처럼 표시하지 않음

## 실행 및 산출물

```bash
python tools/triage_location_candidates.py --archive news_results.json --cache map_visualization/.geocode_cache.json --output test-artifacts/location-review
```

CI의 `test-artifacts/location-review/`:
- `all_articles.csv`: 저장 339건 모든 기사별 근거·플래그
- `flagged_candidates.csv`: 새 규칙에서도 확인을 요하는 기사
- `curated_gold.json`: 22개 실제 기사 정답 및 판정
- `summary.json`: 증거 유형·캐시 적중·검토 후보 수·수동 사례 통과 수

정확한 사건 주소의 독립 정답집이 없는 기사는 정확도/재현율을 주장하지 않고 보류합니다. 이후 작업에선 검토 후보를 수동 라벨로 확장해 위치 오탐과 미탐을 정량화할 수 있습니다.
