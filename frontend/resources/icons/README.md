# Lucide icons

SVG source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
Pinned release: 0.468.0. Original files are bundled unchanged; runtime rendering replaces
currentColor with a semantic color. LICENSE contains the upstream ISC notice. FEATHER_LICENSE preserves the inherited Feather MIT license
from https://github.com/feathericons/feather/blob/v4.29.2/LICENSE. No emoji, icon font, CDN, generated illustration or article-provided SVG is used.

All icon-only controls have accessible names and tooltips. News categories keep their original
backend names; only their visual marker changes. Cluster counts remain numeric quantities.

`bookmark.svg` is an original MapNews outline drawn for the local reading feature,
not an upstream Lucide file. It uses the same 24px grid and 2px stroke.
